# English Dictionary Source

Mnemora 的英语词库适配来源：<https://isdc.pages.dev/>。

该站点页面公开提供约 49,213 个雅思词汇。根据项目使用者提供的信息，作者允许公开获取和使用这些学习资料。Mnemora 不复制站点页面界面，只在用户主动点击下载后读取其公开页面中的词库数据，并在本地生成查询索引。界面始终保留来源链接，词库不会在应用启动时自动联网。

## 数据处理

- 页面中的 `asp-data` 使用自定义 Base85 分段编码和 Brotli 压缩。
- 下载阶段在 Rust 中解码并转换为本地 `index.json` 与逐条 `entries.jsonl`。
- 运行时只按需加载轻量索引；单词详情通过文件偏移读取 JSONL 中的一行。
- 离开英语页面时释放内存索引，但保留磁盘中的本地词库。
- 英音和美音只在用户点击播放时通过来源提供的音频地址加载。

词库原始页面和解压后的中间 JSON 不进入仓库，也不随安装包发布。用户需要在英语学习页面手动点击“下载词库”。

当前仓库另外保存了一份仅包含 `asp-data` 载荷的离线备份，位置为
`src-tauri/resources/english/`。这份备份用于防止来源站点临时不可用，暂不改变
“用户主动下载、按需索引”的运行时策略，也不会自动进入安装包。

来源页面内容可能随作者更新。若作者改变授权或要求停止使用，应移除本地适配并更新本文件。
