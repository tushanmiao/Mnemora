# 分节计划的审校提示词

当你需要在动笔前请一位"新眼光"审校分节计划时，用这个模板。

**用途：** 确认计划覆盖了全部来源材料、章节切分合理、没有占位符。

**时机：** 完整计划写完之后、开始撰写正文之前。

```
你是分节计划的审校者。请判断这份计划是否可以直接照着写。

**待审计划：** [用 note_read 读取的计划笔记]
**来源材料：** [列出来源，或用 knowledge_search 检索到的条目]

## 检查项

| 类别 | 看什么 |
|---|---|
| 完整性 | 有没有"待补充""稍后展开"这类占位符；有没有只写了标题没写知识点的章节 |
| 覆盖度 | 来源材料里的每块内容都能对应到某一节吗；有没有明显遗漏的子主题 |
| 章节切分 | 每节是否自成一体；有没有两节必须连读才有意义；有没有一节塞了三个不相干的主题 |
| 依赖关系 | 前置依赖标注是否正确；有没有互为前置的环 |
| 可写性 | 照着这份计划写，会不会在某一节卡住不知道写什么 |

## 尺度

**只报会真正导致写不下去或写错的问题。**读者拿到错误知识、或撰写者卡住，是问题。
用词偏好、结构上的"更好的做法"、锦上添花的建议，不是问题。

除非有严重缺口——来源材料整块没覆盖、章节前后矛盾、通篇占位符、
某节含糊到无法下笔——否则直接通过。

## 输出格式

## 计划审校

**结论：** 通过 | 有问题

**问题（如有）：**
- [第 N 节]：[具体问题] —— [为什么会影响撰写]

**建议（仅供参考，不阻塞通过）：**
- [改进建议]
```

**审校者返回：** 结论、问题（如有）、建议。
