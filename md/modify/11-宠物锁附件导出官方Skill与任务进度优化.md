# 11 宠物锁、附件导出、官方 Skill 与任务进度优化

## 本次目标

本次改动覆盖四条用户可感知链路：

1. 桌面宠物默认锁定，避免误拖动和误关闭；
2. Markdown 会话导出变为可携带附件的目录包；
3. 深度笔记过程状态只由常驻任务中心承载，移除重复长驻 Toast；
4. 内置 Skill 改为完整上游目录，Mnemora 只在 `mnemora.json` 中保存本地发现元数据。

## 宠物锁

`PetSettings` 新增 `locked` 字段，设置版本升至 16，旧版本迁移时默认锁定。

锁定状态的行为：

- 宠物主体不能拖动；
- 关闭按钮隐藏；
- Tauri 宠物窗口收到系统关闭请求时阻止关闭；
- 双击宠物仍然可以打开主窗口；
- 旁边的小锁是唯一的快速解锁入口；
- 解锁后才允许拖动和显示关闭按钮。

## 附件导出

Markdown 导出现在选择一个目标目录，最终生成：

```text
目标目录/
└── 会话标题/
    ├── 会话标题.md
    └── attachments/
        ├── 原始附件 1
        └── 原始附件 2
```

Markdown 中使用 `attachments/...` 相对链接，图片使用图片链接，其他文件使用普通下载链接。导出过程使用临时目录和原子改名，附件缺失、大小不一致或复制失败时不会留下半成品。重名附件会自动加序号，路径和文件名经过 Windows 安全净化。

JSON 导出仍保持单文件行为，不携带附件二进制。

## 深度笔记进度

深度笔记的 `progress` 状态仍然写入运行时、数据库和任务中心，因此不会丢失，也不会影响重新进入对话时的恢复。

变化只针对展示层：

- 深度笔记阶段进度不再创建输入区附近的长驻 Toast；
- 任务中心继续显示阶段、章节计数、当前活动、工具和 Skill；
- 深度笔记详情页继续显示完整事件与诊断；
- 暂停、完成、失败、取消和遗弃仍显示短暂结果提示；
- 普通 Chat 总结、附件预处理和尚未接入任务中心的 Patch 任务仍保留进度提示。

## 官方 Skill 完整包

当前 `src-tauri/resources/skills` 中保留上游 Skill 的完整目录内容，包括 `SKILL.md`、`references/`、`scripts/`、`assets/` 和上游许可证文件。原始 `SKILL.md` 不再被 Mnemora 中文改写。

每个目录额外有一个 `mnemora.json`，只保存 Mnemora 内部 ID、触发词、默认启用状态、工作模式、Tool 映射以及上游仓库、路径、Commit 和许可证说明。这不是改写官方 Skill，而是应用侧的发现和权限元数据。

脚本会随 Skill 被保存，但当前运行时不会因为读取 Skill 就自动执行脚本。真正执行仍必须经过既有 Tool 目录、权限模式和调用审计。

## 许可证边界

用户自用和非商业目的不等于可以省略许可证。每个 Skill 目录保留其上游许可证，并在 `THIRD_PARTY_NOTICES.md` 记录固定 Commit。Trellis 使用 AGPL-3.0，完整文件随项目分发，因此后续公开发布版本时仍需继续履行 AGPL 的版权和许可证要求。
