# Plan 16 笔记编辑器发布说明

状态：工作区验收记录，未执行 Git commit、推送或应用发布。

Plan 16 将普通笔记、文献笔记和 DeepNote 成品接入同一套 Markdown 编辑会话。编辑器提供 Live、Source 和 Read 三种模式，模式切换保留撤销历史、选区和滚动位置；Read 模式严格只读，大文档会按预算退回 Source 模式。

已交付的日常编辑能力包括标题、强调、删除线、行内代码、列表和任务、引用、链接、搜索替换、大纲、章节移动、硬换行、提示块、高亮、下划线、上下标，以及安全的图片、代码、公式、Mermaid、表格和 HTML 块编辑。表格支持单元格与行列操作、对齐、矩形 TSV 粘贴和结构化撤销；复杂 HTML 合并表格保留原文并提供源码回退。

保存协议使用 note version、SHA-256 内容 hash、operation ID 和 generation。保存前后会检查磁盘内容，失败时保留 durable draft，启动时可恢复文件与数据库的部分提交。AI 局部修改、外部文件冲突、历史版本、固定、恢复、另存和资产暂存都通过同一套版本边界处理。选区引用只有在能证明源码位置时才附带 UTF-8 字节范围，否则只携带版本化摘录。

笔记设置独立于 Chat 设置：旧设置会使用安全默认值迁移；用户可以分别调整笔记字号、行高、中英文混合字体、默认模式、自动保存、自动换行、专注模式、打字机模式、制表位和重型块渲染策略。设置不会写入 Markdown front matter。

## 已知限制

- 浏览器合成事件不能证明所有 Windows WebView2 中文输入法、DPI、拖选和剪贴板驱动组合；这些仍需目标机器实测。
- 历史版本的 128 MiB 软预算和旧外部 Chat 记录的引用发现仍采用保守策略。
- 只有源码映射明确且文本唯一的选区才生成精确范围；渲染块、转义内容或歧义选区只生成版本化摘录。
- Lezer 装饰缓存、复杂表格内联富文本、多行脚注和未知 HTML 的完整兼容，以及重复开关后的长期内存曲线仍未签收。
